# 计算机视觉实验二：图像增强

## 内容

| 文件 | 说明 |
| --- | --- |
| 实验二_图像增强.ipynb | Jupyter版，按2.1~2.6逐节运行，图片直接显示在单元格下方 |
| 实验二_图像增强.py | 脚本版，一次跑完所有步骤并把图片保存到output_images和result |
| 实验二_图像增强_实验报告.docx | 实验报告，含5张结果图 |
| p1.jpg | 原始图像 |
| output_images/ | 色彩空间转换、噪声对比图 |
| result/ | 三种滤波对比、手动中值滤波、自定义高斯核结果 |
| build_report3.py | 生成实验报告的脚本 |

## 实验步骤

2.1 导入依赖
2.2 读取图像、取像素值、BGR转RGB转灰度
2.3 添加椒盐噪声和高斯噪声
2.4 均值、中值、高斯三种滤波对比
2.5 手动实现彩色中值滤波
2.6 自定义高斯核并做二维卷积

## 运行

需要numpy、opencv-python、matplotlib。

Jupyter版：把p1.jpg和notebook放同一目录，Kernel → Restart & Run All。

脚本版：

```
python 实验二_图像增强.py
```

## 结果

图像尺寸(1104,1104,3)，(100,100)处BGR值为(73,84,242)。手动中值滤波耗时约0.7秒，与cv2.medianBlur逐像素最大差值0。自定义7×7高斯核元素和为1。
